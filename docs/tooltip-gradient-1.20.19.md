# 1.20.19 展开介绍动态渐变

展开介绍原先混入 2/3 白色，色彩差异被明显压低。移除该处理，在缓存的主题色板上扩大通道差异，并设 RGB 通道最低值 80、至少一个通道为 255，使颜色更鲜明而不出现暗色文字。保留余乐粉白金、成然星空、神性金白红的语义配色。

使用整页面板坐标计算连续斜向色波，每 180 GUI 像素一个周期、每 2 秒完整循环，避免所有行从同一色位重启。原版字体按字形着色，Modern UI 继续使用完整排版结果的顶点颜色，不把动态颜色写入排版缓存；不增加逐扫描行绘制、描边或加粗。

验证：build/qaJar 成功；原版与 Modern UI 正式映射客户端的展开介绍、Shift 锁定与翻页验收通过；Modern UI 180 帧渐变排版缓存保持 17 → 17。旧版备份后安装 1.20.19，安装文件哈希与产物一致。
