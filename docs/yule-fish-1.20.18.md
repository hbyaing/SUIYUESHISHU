# 1.20.18 抱鱼与物品框接入

参数读取自工作站当前页面，而非预设 JSON：鱼大小 0.72，高度 7.35/16，深度 3.9/16，倾斜 -28°，内收偏航 15°；双臂前伸 50°、内收 ±28°、高低差 0°。沿用原方块手臂，肩部偏移分别为 (+0.04,-0.025,-0.025) 与 (-0.07,-0.025,-0.025)，头部俯仰 -6°、侧倾 -7°。保留跳跃时上举 35°与轻微呼吸。
