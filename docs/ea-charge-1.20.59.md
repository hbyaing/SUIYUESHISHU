# 乖离剑蓄力修正 · 1.20.59

适用 Minecraft 1.20.1 / Forge。手持乖离剑长按右键。

- 第一人称蓄力沿用正常持剑的位置和大小，移除旧版蓄力额外的 0.48 倍缩放与侧倾。
- 第三人称在半秒内举剑过头顶，支持主手和副手；剑柄随手臂运动，剑身保持原尺寸。
- 顶端金环上方增加红色球形光核和外围泛光，从蓄力开始逐渐凝实。光核使用程序着色器，随剑的最终模型变换移动。
- 三段待机转速翻倍，蓄力稳定转速约为旧版四倍：下段每秒 6.67 圈、中段反向每秒 10 圈、上段每秒 8.33 圈。剑柄与金色支架固定。
- 旋转、吟唱与发射声音每个客户端 tick 更新到施法者位置。吟唱期间旋转音降低音量，取消蓄力时一起停止。发射音轨的 9.5 秒尾音跟随人物播放，离开世界或施法者消失时清理。

吟唱时长配置仍使用 `config/starcrowndoll-ea.toml` 中的 `chantTicks = 521`。初始两秒蓄力不计入该值。

升级时替换旧版同名模组，避免同时安装两份以神戴冠 JAR。此轮不改变既有 1000 格、直径 7 格圆柱的服务端破坏逻辑。
