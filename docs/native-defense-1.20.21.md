# 1.20.21 成然原生防御入口

基于仓库1.20.20（746b9db）扩展现有Mixin，不修改余乐能力或客户端布局。

## 改动

- 在LivingEntity、Player与ServerPlayer各自声明的hurt入口先行拒绝成然佩戴者的伤害，不依赖伤害事件最终是否被第三方重新启用。
- 在LivingEntity与Player的actuallyHurt入口补上独立保护，覆盖直接调用内部扣血方法、绕过标准hurt事件的路径，同时避免伤害吸收等前置扣减。
- isDeadOrDying对受保护玩家返回false，isAlive保留isRemoved判断，不把退出或迁移中的已移除实体强行复活。
- tickDeath入口拒绝推进死亡计时并修复显示生命，避免原始deathTime写入后继续跑死亡流程。
- 提取共用攻击尝试处理，在原生拦截早于Forge事件时仍记录反击标记、执行权柄没收，保持既有攻击语义。
- 各新增注入require=1，核对开发名和正式SRG名及完整描述符，不静默跳过关键入口。

仅对服务端当前佩戴/防拆锁定的成然玩家生效。沿用普通背包取下解锁规则；正常维度迁移CHANGED_DIMENSION和退出UNLOADED_WITH_PLAYER仍允许，未给其他玩家/生物全局无敌。

## 边界

Mixin并非JVM隔离边界，不能阻止任意第三方重写全部方法、直接改原生内存或更换实体实现。本次未对所有第三方Boss/武器做通用保证，不新增隐蔽定向补丁。

## 验证入口

`tools/qa/runtime/java/dev/starcrownqa/NativeDefenseTests.java` 包含可独立运行的GameTest及正式重映射客户端验收：正常/非有限伤害、直接内部伤害、吸收生命保留、死亡计时、反击标记、原始头部删除、菜单正常取下、普通头盔伤害以及生命周期豁免。正式附加包测试由enable-native-defense-qa文件开启，不进入发布JAR。

`tools/qa/verify-core-hooks.ps1`核对85组必需注入，包含本次新增8组。方法签名通过不代替实际运行验证。
