# 荒芜之噬轻量浓雾旋涡 · 1.20.51

将确认的第四版黑洞预览接入正式模组：黑色球核、青白边缘、两侧延伸白线，以及有侧面厚度的红黑旋涡雾气。默认使用 LITE 模式，替换旧版多层体积特效。蓄力为蓝色、飞行球为红紫色，落点黑洞保持十秒后收缩，并在原服务端二次爆发时刻显示红色消散球。

## 渲染改动

- 每个效果只积分一个有边界的三维雾团，每条有效射线 12 次采样、每次两层三维噪声。核心和白线使用解析交点；不采样旧特效贴图，不加载旧版 72 个特效网格及曲线。
- 原生场景深度截断雾气、球核与白线；默认半宽高 RGBA16F 积分，经过深度约束的四点重建后合成。球核也在此缓冲内，低比例会柔化细边。
- 总积分像素预算默认 360000，多个可见效果平分预算。按每个效果投影范围裁剪；每帧重新绘制，不限速或缓存相机画面。一次深度复制供本帧所有效果共用。
- 在粒子后记录真实地形矩阵，云层后合成。通过逆投影恢复光学眼点，涵盖投影中的视角晃动平移。前景实体与不透明地形使用实际场景深度。
- 缓冲按尺寸复用；资源重载及退出释放。编译或渲染故障退回基础几何，直到重载再重试；单独重建程序不可用时按原生分辨率绘制轻量场。
- 服务端伤害、牵引范围、技能时序与投射物运动代码未修改。原有神环与翅膀资源不变。

## 安装与配置

使用 [1.20.51 JAR](../../releases/1.20.51/YiShenDaiGuan-1.20.1-1.20.51.jar) 替换旧版以神戴冠，只保留一个版本；联机双方使用同版。仍需要 Minecraft 1.20.1、Forge 47.4.0+、Java 17、Curios 5.14.1 和 GeckoLib 4.8.4-mesh.9。

客户端文件为 `config/starcrowndoll-client.toml`，关闭游戏后编辑并重启；运行中改模式需 F3+T 重载资源。

```toml
huangwuMode = "LITE"
huangwuVolumeResolution = 0.5
huangwuLiteMaxPixels = 360000
```

| 模式 | 行为 |
| --- | --- |
| LITE | 默认，新版 12 采样浓雾旋涡 |
| LEGACY | 原版 48 步多层体积，恢复旧网格和贴图 |
| BASIC | 原版着色器基础几何，用于兼容 |
| OFF | 隐藏荒芜之噬视觉，技能仍正常运行，用于排障 |

较弱显卡可把比例改为 `0.33`，总像素预算改为 `160000`。预算限制仅作用于 LITE；原生画质对照需同时将比例设为 `1.0`、预算提高到窗口像素数以上。

## 验证及边界

详见同目录的 `release-audit.json`、`gpu-summary.json`、`lite-results.txt`、`lite-lifecycle.txt` 和实机截图。GPU 计时包含此效果的深度复制、核心、雾气、白线及合成，不包含整游戏、龙模型和其他模组开销。它不是 Intel UHD 或整游戏 FPS 的测量。

验证宿主为 Minecraft 1.20.1 / Forge 47.4.26 / Java 17 / RTX 4060 Laptop GPU / 1280×800 原版渲染管线。未验证 Intel UHD、第三方光影、Fabulous 透明管线和大量交叠效果的复杂透明排序。雾气为艺术化程序密度场，无真实引力透镜或流体模拟。

本次共通过 63 项运行时检查。新模式 GPU 中位耗时：落点近景 0.4413 ms、贴近球面 0.8817 ms、侧面 0.3983 ms（默认半宽高）。这些数据仅对应本机 RTX 4060 Laptop；小面积蓄力/飞行球的额外合成成本可能使半分辨率略慢于同版原生分辨率，不能把低分辨率描述为所有视角都更快。

## 源码及复现

`tools/huangwu-lite.glsl` 保存已确认的 v4 内核；`tools/build-huangwu-lite.py` 生成 GLSL 150 宿主和参数 JSON，`--check` 核验生成一致性。Java 入口为 `HuangwuLiteRenderer`；`MingGuLongHuangwuVfx` 按配置分流。

```powershell
python tools/build-huangwu-lite.py --check
./gradlew.bat --offline --console plain -Pqa build qaJar
```

QA 附加包仅用于隔离存档，不能装入正式游戏。建立 `enable-huangwu-lite-qa` 文件后自动完成 11 场景、每场景 24 对真实 GPU 查询，再执行真实服务端实体、移动、尺寸变化、预算、重载、注入编译故障及退出检查。正式 JAR 不包含 QA 类和 GPU 计时查询。
