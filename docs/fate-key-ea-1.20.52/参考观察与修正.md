# 根部斜肩修正

参考原图 1349×900，圈注位于 (600,270)–(840,410)。该区可见长直边之后有一段向内的斜肩，接入护盘，不能把长板校直理解成删除斜肩。

本轮只修改已校直 Mesh 的 105、253 两个根部端点（正背厚度层），保留 106、254 斜肩起点与全部其他顶点。斜肩纵向长度 0.55990，横向退让 0.25461；沿用原模型的斜肩方向与退让量。拓扑和厚度不变，孔洞、齿槽、握把与台座不变。

已检查：固定正交正面、原英雄斜视，根部内收恢复，长直段保持平行。输出模型与当前 live 场景副本均已保存；live 对象原平移保留。预览使用 RTX 4060 Laptop GPU / OPTIX。

参考是带透视的动画画面；正交图用于诊断直边和斜肩，不冒充逐像素还原。隐藏背面细节未从这张参考独立验证。
