# 王律之键与乖离剑：首版游戏接入

Minecraft 1.20.1 / Forge 47.4.0 / Java 17。新增 `starcrowndoll:bab_ilu` 与 `starcrowndoll:ea`，均为原始三角形 Mesh 物品；王律之键保留斜台座、镂空握把和已确认的钥齿。乖离剑保留用户提供 FBX 的 8 个部件、UV 和底色，剑身发光纹使用独立发光贴图。

## 获取与使用

- 创造分类「以神戴冠」；也可 `/give @s starcrowndoll:bab_ilu` 或 `/give @s starcrowndoll:ea`。
- 钥匙合成：上方金锭，中排金锭 / 下界之星 / 金锭，下方绊线钩。
- 手持钥匙长按使用 8 秒。完成后当前手换成乖离剑，钥匙放回背包；背包满时仅将保留的钥匙掉在玩家身边。
- 松开取消，不发剑；已有乖离剑时拒绝再次取剑。完成冷却 10 秒。
- 乖离剑首版使用普通近战逻辑：10 点面板攻击伤害、1.2 攻击速度、钻石级耐久。没有蓄力、光炮或地形破坏。

## 参考与时序

参考用户指定的 [《Fate/strange Fake 黎明低语》片段](https://www.bilibili.com/video/BV1BkZiBkETv/?t=2535)。实际取剑关键段约 42:29–42:37。

| 游戏 tick | 表现 |
|---|---|
| 0–66 | 钥匙举起，中心粗主干与三面斜岔向上展开 |
| 30–114 | 周围断续红色风压，纯空间 GLSL 场积分，不使用风线曲线或贴图 |
| 80–114 | 金色亮面出现，手臂向前伸入，解析结构收束 |
| 114–134 | 黑色画面保留可见手臂 |
| 134–140 | 手部先迸发交叉白光 |
| 140–158 | 黑色遮挡面沿不规则三角分块旋转、分离并飞散，露出世界与握住的剑 |
| 160 | 服务端完成取剑，当前手换成真实剑物品 |

关键修正：黑色画面本身碎裂；没有将这一段简化成“金色圆环中缓慢抽出完整剑”，也没有只在手边生成碎屑粒子。游戏对原片的对白停顿作了压缩。

## 资源与渲染

- `tools/fate/export_assets.py` 从用户本地 Blender / FBX 来源导出，源文件不被覆盖。钥匙 50,384 三角形；乖离剑 10,474 三角形；解析结构来自已确认工程的 485 条曲线。
- 解析结构在资源加载时生成并上传静态 VBO；每帧只更新时序及矩阵。
- 客户端构造阶段显式挂接资源重载监听器，监听器在渲染执行器上加载、关闭并重建自有着色器。风压与透明叠加在资源 JSON 中明确设置 alpha 混合。
- 风压使用包围体代理与 48 步 GPU 积分；金色亮面和交叉白光为程序着色器。碎屏使用固定种子的共边三角片，裂开前完整覆盖。
- 服务端广播维度、施术玩家、起始 tick 和锚点；旁观者接收同一个动作时钟。第一人称使用屏幕黑色遮挡面，旁观者使用手部附近的空间遮挡面。
- 取消、离线、死亡和换维度清理动作状态；资源重载重建网格与着色器。网络协议更新为 9，服务端和客户端必须同版本。

## 素材来源

王律之键及解析线来自本次按参考制作并经用户修正的 Blender 工程。乖离剑来源为用户提供的 `Sword of Rupture_ Enuma Elish _爱给网_aigei_com.zip`，其中 `EA.fbx` 与底色/发光图；压缩包未附明确许可文本。这里只记录用户提供的来源，不将该素材标记为原创或开源授权。仓库未加入原 ZIP 或无运行用途的 PBR 原图。

## 验证记录

- Java 17 离线 `build` 与 `reobfJar` 完成。
- Forge GameTest 使用隔离存档，人工玩家驱动原生 use tick；完整取剑、取消、满背包钥匙保留、拒绝提前完成、副手取剑及替换物品栈取消共 **6 项通过**。最终结果附在同版验收目录。
- NVIDIA GeForce RTX 4060 Laptop GPU / OpenGL 3.2：生产 GLSL 编译与链接通过，独立离屏绘制 `GL_NO_ERROR`。独立 GPU 预览不等同于 Minecraft 实机截图。
- 实际 Forge 客户端使用 RTX 4060：启动资源加载、主手第一人称真实长按、服务端发剑同步、真实资源重载、副手第三人称取剑均保存截图和结果。截图采样的 OpenGL 错误码均为 0。
- [实机关键帧](fate-key-ea-1.20.51/sequence.png) · [验收结果](fate-key-ea-1.20.51/client-results.txt)。关键帧序列不是原片，也不是连续视频录制。
- 本版保留 Minecraft 原版方块手臂；未实现原片手指张开/握紧的独立骨骼与彩色分离。第三人称黑面为局部空间特效；第一人称为完整屏幕遮挡。尚未验证 Oculus / Iris、外部光影、多人远程服、地形贴面时的体积风压深度截断及大量玩家同时施术的性能。
