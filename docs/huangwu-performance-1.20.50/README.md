# 荒芜之噬性能优化 · 1.20.50

荒芜之噬的蓄力、飞行球和落点球使用较小缓冲进行体积积分，再按原场景深度还原到屏幕。默认宽高各为窗口的 50%，最重的体积积分处理约四分之一的像素。保留现有三维密度场、48 步射线预算、模型、配色、动画、技能伤害、吸引范围和时序。

## 本版改动

- 实心核心、贴图网格与放射光线保持原生分辨率。每个体积层在原有透明排序位置积分并立即合成，保留模型与体积的穿插关系。
- RGBA16F 中保存预乘颜色，用四点重建颜色和透明度。原生深度判断前后景，并对斜面预测深度变化；按实际深度纹素中心比较，避免斜地面上的条纹和缺口。
- 投影包围盒在近裁剪面求交后裁剪屏幕范围，剔除屏幕外部分。很小的效果直接按原生分辨率绘制，省去额外合成。
- 资源加载时提前解析动画曲线、解压并上传 72 个网格缓冲、加载贴图，减少第一次蓄力/释放时的同步资源工作。
- 每帧共用逆投影矩阵；深度副本和积分目标按尺寸复用。资源重载关闭旧网格和缓冲；断开连接释放两个离屏目标。
- 重建程序或浮点缓冲不可用时保留原生体积绘制；主着色器不可用时继续使用已有基础几何特效。故障后等资源重载再重试。

## 画质设置

启动一次后，客户端生成 `config/starcrowndoll-client.toml`。关闭游戏后编辑：

```toml
huangwuVolumeResolution = 0.5
```

| 数值 | 用途 | 体积积分像素约占原生 |
| --- | --- | --- |
| `0.5` | 默认，平衡效果与开销 | 25% |
| `0.33` | 较弱 GPU 可选 | 11% |
| `1.0` | 原生体积画质 | 100% |

允许范围 `0.25`～`1.0`。较小比例会柔化细小烟雾和薄边缘；实体核心与模型轮廓仍按原生分辨率处理。

## 测量与验收

正式混淆 JAR，Minecraft 1.20.1、Forge 47.4.26、Java 17、NVIDIA GeForce RTX 4060 Laptop GPU，窗口 1280×800，原版渲染管线。

独立 QA 模组调用正式渲染入口，在同一帧交替绘制 `1.0` 和 `0.5`。每次还原同一份场景颜色/深度，固定技能年龄、相机和投影；每个场景暖机 12 对，再取 24 对 GPU timer query 的中位数。原生对照使用真实 1280×800 主颜色附件和视口。计时包含本特效的核心、深度复制、网格、体积与重建；整个游戏和龙模型本体的其他渲染不包含在此范围。正式 JAR 不含计时查询或 QA 类。

| 场景 | 原生体积 / ms | 默认半宽高 / ms | 本特效耗时下降 |
| --- | ---: | ---: | ---: |
| 落点近景 | 1.79 | 0.93 | 48.4% |
| 落点远景 | 1.29 | 0.84 | 35.1% |
| 蓄力 | 2.55 | 1.28 | 50.1% |
| 释放后的飞行球 | 2.74 | 1.28 | 53.5% |
| 贴近球面/近裁剪面 | 10.63 | 3.24 | 69.5% |
| 低视角地面与实体 | 2.95 | 1.64 | 44.3% |

数据见 [GPU 汇总](gpu-summary.json)、[原始 GPU 查询](performance-results.txt) 和 [截图对照](paired-contact-sheet.jpg)。

对照覆盖落点近景/远景、蓄力、释放后的飞行球、贴近近裁剪面和低视角地面/实体轮廓。独立生命周期验收使用真实服务端生成的龙与漩涡，检查移动、转向、961×601 奇数尺寸、0.33 配置、编译失败备用路径、重载恢复及退出清理，记录见 [着色器回归](shader-results.txt)、[生命周期回归](lifecycle-results.txt)。

当前 GPU 实测不能替代低配置电脑上的整游戏帧率测量。第三方光影组合未在本次验证范围内。

## 复现

```powershell
$env:JAVA_HOME = '<Java 17 目录>'
./gradlew.bat --offline --console plain -Pqa build qaJar
```

独立客户端安装正式 JAR、`YiShenCombatQA-1.20.50-test.jar`、Curios 和 GeckoLib mesh.9。性能测试在游戏目录创建 `enable-huangwu-performance-qa`；生命周期测试另起客户端，创建 `enable-huangwu-shader-qa` 与 `enable-huangwu-lifecycle-qa`。使用隔离存档，测试会布置地面、移动相机并在结束后退出。

```powershell
python tools/summarize-huangwu-performance.py <性能客户端目录> <报告目录>
```

联机客户端与服务端使用同一版本；帧率档位配置只影响客户端绘制。
