# 永恒恶龙 1.20.42：实时 Boss 血条

Minecraft Java 1.20.1 / Forge 47.4.0+ / Java 17。日期：2026-11-16。

## 实际行为

永恒恶龙使用已定稿的黑红血槽、中央模型侧面像素龙头和左右龙翼。名字由游戏字体实时绘制，不显示减伤。红色血量层从左向右按当前生命值 / 当前最大生命值裁切；边框、龙头和龙翼独立绘制，掉血时不会被切掉。

服务端每 tick 更新 `ServerBossEvent`，通过 Minecraft 原生 Boss 事件包同步给正在追踪该实体的玩家。受伤、吸血、其他回血和最大生命值变化都参与比例计算；NoAI 下仍然更新。客户端采用原版约 100 ms 的血量插值，不使用固定的示意血量。

离开实体追踪范围时取消该玩家的血条；重新进入时恢复。死亡时隐藏，移除或卸载时清除订阅。每只龙有独立 Boss UUID，多只龙分别显示。客户端只替换专用翻译标记的永恒恶龙血条，其他 Boss 使用原有界面；命名牌名称保留。

HUD 最大宽度为 320 个 GUI 单位，小窗口按可用宽度缩小。层贴图使用最近邻采样。绘制与原版 Boss 栏布局共存；原版屏幕高度上限仍然适用。

## 一并提交的此前成果

- 原生 JSON 模型接入、480 Cube / 370 骨骼 / 22 段动作及配套贴图。
- 战斗状态机、追击与飞行切换、爪击接触帧和荒芜之噬的蓄力、飞弹、落点效果。
- 落点约 5 格视觉范围、10 秒黑洞、9×9×9 吸引范围、接触持续伤害每 tick 20 点，以及按实际生命损失 40% 吸血。
- 火焰免疫、不着火、黑底红斑生成蛋。
- 玩偶与第一人称施法身体渲染的可见性修复。

动态减伤此前仅提出过方案，本版没有将该方案作为已完成功能加入。

## 安装与源码

[下载正式 JAR](../releases/1.20.42/YiShenDaiGuan-1.20.1-1.20.42.jar)，放入 `mods`，只保留一个以神戴冠版本。客户端与服务器使用相同版本，并保留 `geckolib-forge-1.20.1-4.8.4-mesh.9.jar`；QA 模组不随正式版发布。

源码位于 `src/main`。`libs` 保存构建所需的指定 GeckoLib 与数学 API；不把它们嵌入正式 JAR。依赖用途见 [libs 说明](../libs/README.md)。血条图层及可再生工具见 [血条素材目录](../tools/eternal-dragon-bossbar/README.md)。
