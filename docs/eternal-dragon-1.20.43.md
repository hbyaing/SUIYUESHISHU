# 永恒恶龙 1.20.43：死亡动画播放完成后移除

日期：2026-11-16。Minecraft Java 1.20.1 / Forge 47.4.0+ / Java 17。

## 修复

原来的实体继承原版 `tickDeath`，在第 20 tick（1 秒）移除，但 `Fight_Die` 的最后关键帧位于 2.9667 秒，导致死亡动画被截断；NoAI 分支还会跳过死亡状态切换。

现在致命伤害会立即切换 `Fight_Die`，只播放一次并保持最后一帧。按实际动画长度取整为 60 tick，额外保留 2 tick 给最终画面同步，第 62 tick（正常 20 TPS 下约 3.1 秒）由服务端发出死亡粒子事件并移除实体。客户端不再自行使用 20 tick 的移除阈值。

死亡逻辑在 NoAI 判断之前执行；尸体停止追击、施法选择和近战，Boss 血条立即隐藏。渲染器关闭原版附加的死亡侧翻，使用模型自带的倒下动作。空中死亡恢复重力。保留原版/Forge 的死亡回调、击杀归属、经验与掉落入口，不在死亡计时中重复结算。

尸体在死亡过程中卸载再重载时，会重新播放完整死亡动画后移除，避免保留旧死亡计时却从第一帧闪退。原有模型、贴图、动作数据和血条素材没有修改。

## 验证

- 正式 JAR、隔离 QA JAR 构建通过。
- `starcrownbossqa` 独立 GameTest 服务端共 3 项必需测试通过：包含此前血条生命周期测试，以及开启 AI / NoAI 的完整死亡计时、从飞行/技能切换、死亡状态不重复启动、禁止尸体近战、掉落与经验不重复、尸体存档重载。
- 正式混淆 JAR 在 RTX 4060 隐藏独立客户端检查存活、死亡开始、中段、结束和移除五种状态。证据位于 [验证目录](eternal-dragon-1.20.43/)。
