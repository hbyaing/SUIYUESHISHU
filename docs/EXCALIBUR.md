# 誓约胜利之剑与阿瓦隆

《以神戴冠》1.20.56 公开版基于主仓库 1.20.53（`1e088ac`）。两件宝具取自《Fate/stay night》阿尔托莉雅·潘德拉贡的经典 Saber 形态。圣剑在 Blender 中重新建模并绘制专用贴图，以 Aniplex 的等身圣剑及官方商品照片校准形状。阿瓦隆的蓝金纹样和鞘尖参考了 Hobby JAPAN 拍摄的 Good Smile 模型特写。明剑、空鞘和入鞘三种状态均使用有厚度和 UV 的 OBJ 网格。[等身圣剑](https://store.aniplexusa.com/fsn/excaliber-standard-edition/) · [剑鞘特写](https://hjweb.jp/article/525262/) · [Blender 源模型](../models/excalibur/Excalibur_and_Avalon.blend)

## 安装与获取

使用 Minecraft Java 1.20.1、Forge 47.4.0 或兼容的 47.4.x 版本和 Java 17。将新版《以神戴冠》JAR 及下方两个运行前置放进实例的 `mods` 目录。升级旧实例时用新版替换旧版主模组。联机的客户端和服务端都安装相同版本。

- [以神戴冠 1.20.56](../releases/1.20.56/YiShenDaiGuan-1.20.1-1.20.56.jar)
- [仓库配套 GeckoLib 4.8.4-mesh.9](../libs/geckolib-forge-1.20.1-4.8.4-mesh.9.jar)
- [Curios 5.14.1+1.20.1](../libs/curios-forge-5.14.1+1.20.1.jar)

公开版随 JAR 提供两段无人声蓄力音效，实机演示采用同一音轨。若持有可供个人使用的两段日语 WAV，可以生成客户端资源包并在游戏设置中启用。联机时，每位玩家听到自己启用的资源包。[个人日语资源包制作方法](EXCALIBUR_ASSETS.md#个人日语资源包)

创造模式打开「以神戴冠」分类。管理员也可以分别给予两件物品。

```mcfunction
/give @s starcrowndoll:excalibur
/give @s starcrowndoll:avalon
```

生存模式取得下界之星后，两份工作台配方会进入配方书。下表每格依次列出工作台该行的左、中、右三格。

| 工作台 | 誓约胜利之剑 | 阿瓦隆 |
|---|---|---|
| 第一行 | 空、空、下界之星 | 金锭、青金石块、金锭 |
| 第二行 | 空、钻石剑、金锭 | 金锭、下界之星、金锭 |
| 第三行 | 烈焰棒、金锭、空 | 金锭、紫水晶碎片、金锭 |

## 圣剑

新获得的圣剑带有风王结界。持剑时金属剑身隐去，半透明的白色风压从护手处一路缠绕到剑尖。平举、挥砍和蓄力时风纹都会沿剑身流动，显形或收剑入鞘后风压消散。物品栏仍显示圣剑图标。两种形态都可正常近战。以下操作采用原版默认键位，修改键位时以「使用物品」和「潜行」的绑定为准。

普通渲染下，第一人称剑身背后的砖缝等纹理会被压缩气流轻微折弯。只采样本地隐剑投影覆盖的一小块画面。在第三人称或装有 Oculus、Iris、OptiFine 的实例中，风王结界用透明的白色风纹表现。[《Unlimited Blade Works》第 7 话官方剧照](https://www.fate-sn.com/ubw/story/08.html)

[举剑、冲天与下劈实机演示](excalibur/excalibur-invocation.mp4) · [七格蓄力光场](excalibur/excalibur-charge-field.png) · [双手吟唱](excalibur/excalibur-chant.png) · [光束落点](excalibur/excalibur-impact.png) · [白色风压动图](excalibur/invisible-air.gif)

第一人称平时可看见持剑侧的原版皮肤手臂，单手把圣剑竖在身侧。发动 EX 时，圣剑移到画面正中，蓝金纹饰的宽剑面朝向玩家。一手握在护手下方，另一手握在剑首上方，两臂沿用玩家的经典臂或细臂模型和袖层设置。改用左手时整套动作镜像。蓄力期间另一只手里的武器、盾或剑鞘暂时隐藏，发射或中断时自动恢复。[第一人称实机图](excalibur/first-person.png)

第三人称下，圣剑从剑首到剑尖约 1.61 格，相当于站立玩家身高（1.8 格）的九成。日常持剑时，另一只手空着就会双手握柄，拿着物品时则单手持剑。发动 EX 时，玩家周围半径七格的圆内浮起剑身同款金色光点。第一段蓄力声将尽时双手举剑过顶，剑尖喷出有厚度的金白光柱。两秒停顿后，第二段音效响起，持剑者向后蓄势，再向瞄准方向下劈并收势。[玩家身高校准图](excalibur/player-scale.png) · [第三人称实机图](excalibur/two-handed.png)

| 操作 | 战斗效果 |
|---|---|
| 左键攻击 | 基础总攻击伤害 12，攻击速度 1.6，剑身不损耗耐久。 |
| 潜行时右键 | 隐匿或显现剑身，切换间隔 0.4 秒。 |
| 剑身隐匿时按住右键 | 偏转从正面飞来的箭和三叉戟。蓄力 0.6 秒后松开，沿视线打出风王铁槌，范围最远 24 格，基础伤害 12 并击退命中者。压缩的风释放后，圣剑自动显形，冷却 3 秒。 |
| 剑身显形时按住右键 | 举剑 0.5 秒后开始蓄光，此时可松开右键继续瞄准。金光冲天后，蓄力声中间停顿两秒。从第一段音效起点计 11.60 秒，光束沿最终准星自动发射。射程最远 64 格，基础伤害 40，可命中路径上多个目标，冷却 15 秒。 |

隐剑的风王铁槌会提示松开释放。显形圣剑开始蓄光前松手可以取消，蓄光中切走圣剑、换手或展开阿瓦隆也会中断。风王铁槌和 EX 分别积累 1 和 4 点原版饥饿消耗值。两种攻击都会在有碰撞的方块处停止，地形得以保留。技能会跳过盟友、主人自己的驯服生物，并遵从服务器的 PvP 设置。面板伤害以原版生命值计，2 点相当于一颗心，实际伤害受护甲等因素影响。

## 阿瓦隆

| 操作 | 剑鞘效果 |
|---|---|
| 随身携带 | 受伤时每 4 秒恢复一颗心。任一只手持圣剑时缩短到每 2 秒。携带多份时按一份计算。 |
| 主手剑鞘、副手圣剑，潜行右键 | 收剑，鞘口露出护手与剑柄。原剑的名称、附魔和风王结界状态随剑保存。 |
| 主手持已收剑的鞘、副手留空，潜行右键 | 圣剑回到副手。 |
| 持鞘右键，或随身带鞘时按 V | 主动解放「遥远的理想乡」。金色护界跟随持有者 5 秒，清除已有负面效果，隔绝常规伤害、爆炸冲击、击退及新施加的负面效果，结界中也无法对外造成常规伤害。 |

V 键可在控制设置中更改，双手持剑与鞘时也能使用。护界冷却从展开时起计 45 秒。冷却期内仍可收剑、拔剑，尝试再次展开时会显示剩余秒数。管理员 `/kill` 保留作用。

## 模型与贴图

圣剑由六个可编辑网格组成，使用一张 512×1024 的不透明贴图。刃尖末段连续收窄，中脊通向尖点。护手用暖金与琥珀色表现反光，其金面在游戏的物品绘制过程中随视角变化，并受环境亮度影响。阿瓦隆使用一张 256×2048 的不透明贴图，空鞘与入鞘共用。[空鞘与入鞘的游戏画面](excalibur/avalon-in-game.png) · [Blender 几何与校准](../models/excalibur/SWORD_GEOMETRY.md) · [贴图与 UV 分区](../models/excalibur/SWORD_MATERIAL.md)

| 展示状态 | 1.20.54 Forge 烘焙面数 | 1.20.55 Forge 烘焙面数 |
|---|---:|---:|
| 显形圣剑 | 2720 | 1068 |
| 阿瓦隆空鞘 | 376 | 376 |
| 圣剑入鞘 | 1184 | 1128 |

银刃、金翼和剑根共用物品图集。金面高光沿用原有网格与纹理采样。纹理以 RGBA8 换算，新版圣剑独立基础层约 2 MiB，较 1.20.54 多 0.75 MiB。

在 RTX 5060 Laptop、Forge 47.4.0 上，把 16 件物品绘制到同一块 640×640 离屏画面，每轮交替测量两个版本。预热 10 轮、采样 35 轮后，从 CPU 提交到 GPU 完成的每批耗时中位数，明剑从 9.96 毫秒降到 3.52 毫秒，入鞘从 4.60 毫秒降到 3.60 毫秒。两个版本的物品与方块总图集均为 2048×2048。这些数据衡量该机器上的物品绘制耗时。[剑尖对照](excalibur/tip-comparison.png) · [护手对照](excalibur/guard-comparison.jpg)

原版 Minecraft 玩家没有年龄属性，剑鞘停滞衰老的原设以背景设定体现。时长、射程、伤害、合成成本和冷却均为本模组的玩法设计。[《Fate/side material》剑鞘条目](https://www.tmdict.com/ja/su.avalon) · [TYPE-MOON 的圣剑与风王结界展示](https://typemoon.com/contents/fate-stay-night/w5n1yv)

## 源码与素材

在仓库根目录使用 Java 17 执行 `gradlew.bat build`，构建输出位于 `build/libs`。本地开发同时提供 `gradlew.bat runClient`。独立的服务端能力测试在 `tools/qa` 内，使用 `gradlew.bat -Pqa -PqaGameTestNamespace=excaliburqa runGameTestServer` 运行。

用 Blender 打开 [Excalibur_and_Avalon.blend](../models/excalibur/Excalibur_and_Avalon.blend)。圣剑和阿瓦隆分属两个集合。剑鞘采用一个网格，鞘口的上下金唇和可容纳剑刃的内壁都有厚度。两面的钴蓝宽带、细金线、黑色短铭和铜金端饰共用一张静态不透明贴图。短铭根据照片绘成装饰字形。空鞘与入鞘共用这张贴图。[可编辑的剑鞘绘图脚本](../models/excalibur/paint_avalon.py)

正交相机可检查剑脊、弧形护手与蓝金鞘纹。鞘尖内径按此模型的剑尖留出，因此包尖比参考照片略宽。编辑后在仓库根目录运行以下命令，可将明剑、空鞘和入鞘组合重新导出到模组资源目录。

```powershell
blender -b models/excalibur/Excalibur_and_Avalon.blend --python models/excalibur/export_forge.py
```

剑风、聚光、光束、护界和命中演出使用 Kenney 的网络素材在游戏内组合。10 个空间音效由下载的采样混音，真名解放的双段音轨取自其中三项。声音与特效在游戏中均可离线使用。[逐项来源、许可与音轨重建方法](EXCALIBUR_ASSETS.md)
