# 永恒恶龙 1.20.41

更新日期：2026-11-16
环境：Minecraft Java 1.20.1 / Forge，保留用户提供的 geckolib-forge-1.20.1-4.8.4-mesh.9.jar。

## 本轮更新
- 永恒恶龙免疫火焰、持续燃烧、岩浆、岩浆块等火焰类伤害；不会被点燃，也不显示燃烧火焰。
- 所有攻击恢复实际造成生命损失的 40%，包含近战、落点爆炸、黑洞持续伤害和消散爆发。免疫、取消、仅吸收黄心和溢出伤害不计入吸血；回血不超过 666 上限。
- 仅荒芜之噬落点黑洞整体等比放大至约 5×5×5 格级别；黑核、烟雾、地面旋涡一同缩放，蓄力和飞弹保持原尺寸。烟雾边缘随动画流动，尺寸按可见密度域估算。
- 落点特效按地面接触点缩放，修复放大后地面旋涡沉入方块的问题。
- 黑洞保持 10 秒、9×9×9 格吸引范围；接触生成点 1.5 格半径内每 tick 扣除 20 点生命值，绕过普通受伤无敌间隔。
- 保留落点固定 200 点虚空伤害、不破坏地形、穿盾穿甲、同类免疫及原有战斗与飞行逻辑。
- 生成蛋使用已确认的原版轮廓、纯黑底色和纯红斑点，移除额外颜色叠染。
- 模型几何、骨骼、动画、身体贴图及 GLSL/特效网格均与 1.20.40 保持一致。

## 使用
将 YiShenDaiGuan-1.20.1-1.20.41.jar 放入 mods，仅保留一个 YiShenDaiGuan 版本。已安装的游戏需要重新启动后生效。此包不含依赖 JAR，也不含测试模组。

## 验证
隐藏独立客户端使用 NVIDIA GeForce RTX 4060 Laptop GPU 运行；验证了四种爪击、溢出/免疫/事件取消/吸收黄心、多目标爆炸、200 个连续 tick 的扣血和吸血，以及火焰/岩浆/强制着火状态。
验证记录目录含实际 GPU 截图与日志，5 格地面标尺用于核对落点视觉范围；生成蛋截图来自正式物品渲染器。外部光影组合未在本轮另行测试。
