# 恩奇都跟宠 · 1.20.54

手持王律之键长按右键八秒，拔剑成功时，当前手的钥匙变成乖离剑并召唤恩奇都。松手取消不会召唤。每位召唤者只有一只，恩奇都不参战、没有血条、不可选中且不受伤。它会在附近寻路，掉队时追上；主人换维度、重进世界或重生后会在附近重新出现。

手持乖离剑潜行并对空右键，当前手的剑变回王律之键，并遣返自己的跟宠。再次拔剑时仍遵循原有冷却。

模型来自提供的 `恩齐都.bbmodel`。游戏资源保留 118 个 Cube、25 个骨骼、三张原贴图的 UV 和六段动画；跟宠自动切换待机和跑步。重新导出：`python tools/fate/export-enkidu.py <恩齐都.bbmodel>`（需要 Node.js 和 Pillow）。
