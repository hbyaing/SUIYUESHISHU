## 安装与升级

| 项目 | 要求 |
|---|---|
| Minecraft | Java 版 1.20.1 |
| 加载器 | Forge 47.4.0 起，使用兼容的 1.20.1 构建 |
| Java | Java 17 |
| 主模组 | `YiShenDaiGuan-1.20.1-1.20.72.jar` |
| 必装前置 | [GeckoLib 4.8.4-mesh.9](libs/geckolib-forge-1.20.1-4.8.4-mesh.9.jar) 与 [Curios 5.14.1+1.20.1](libs/curios-forge-5.14.1+1.20.1.jar) |

把主模组与两项前置放入实例的 `mods` 文件夹，删除旧版主模组后重启。联机客户端和服务器安装相同版本及前置。项目使用指定的 GeckoLib mesh.9 构建，直接使用仓库配套文件；`mclib-20.jar` 仅供编译，不需要另外放进 `mods`。[依赖说明](libs/README.md)

Curios 自 1.20.44 起为必装前置。早期文档中“无 Curios 独立饰品栏”的说明属于历史实现，不能作为 1.20.72 的安装方式。

创造模式内容集中在「以神戴冠」分类。Ea 不在创造分类及搜索中直接展示，正常通过王律之键拔出。

## 五种玩偶与神性

### 共通交互

对空气右键可戴到空闲头盔槽，对方块右键可摆放；也可把玩偶装入 Curios 神格槽。头盔槽和神格槽合计只允许装备一个玩偶，神格玩偶可与普通头盔共存。正常从背包取下即可解除对应穿戴能力。

成然、微光、余乐和闲游拥有对应神性；**自我玩偶目前提供个性化外观，不附送前四种神性的战斗能力**。摆放的自我玩偶记录摆放者皮肤，不播放音乐。

### 成然玩偶·微光：余晖神性

保留成然主题与面板，提供有限强度的七项能力：

1. 普通伤害减免 60%，单次最多损失最大生命值的 35%；虚空与即死照常结算。
2. 创造飞行、移速 +35%、挖掘速度三倍；可开关夜视及 3×3×3 / 5×5×5 范围采掘。
3. 主动近战、远程及可追溯法术伤害 +50%，单次额外伤害最多 60 点。
4. 受敌对生物攻击后标记十秒，下次命中触发四秒四次追偿，总量为目标最大生命值的 12%，最多 120 点；同目标冷却十二秒。
5. 16 格领域持续十秒，暂停普通敌对 AI、拦截投射物，领域内自己与队友所受首领伤害降低 20%；结束后冷却四十五秒。
6. 两次 64 格安全瞬移，每十二秒恢复一次；三个跨维度锚点，成功返回消耗 1000 经验，共用六十秒冷却。
7. 自身或 24 格内队友、驯服宠物致命时，先使用目标自己的图腾，否则免费救援至 40% 生命并免伤三秒；佩戴者和获救者各冷却 180 秒。

### 余乐玩偶·闲游：清欢神性

适合希望保留资源与冷却约束的生存玩法：

- **谦逊**：常驻 35% 减伤，单次普通伤害至多损失 40% 最大生命。
- **宽容**：主动十二格和平领域，持续八秒，拦截普通敌对投射物；结束后冷却四十五秒。
- **慷慨**：潜行 + Q 赠出整组原物，其他玩家拾取后双方获得六十秒村庄英雄 II，冷却 120 秒。
- **贞洁**：常规负面持续时间缩短 60%，三格内液体凝结可开关。
- **节制**：饥饿消耗减少 75%，装备有 50% 概率免除单次耐久消耗。
- **仁爱**：治疗残血队友或自己的宠物 40% 最大生命，并给予十秒抗性 II，冷却二十五秒；最多三个动物/村民契约，十六格内共用六十秒馈赠间隔。
- **勤勉**：劳作时急迫 IV、速度 II，停下五秒消退；步行十六格或挖一个天然方块积一点进度，每十点给二十经验，每百点永久 +1 生命上限与 +0.25 幸运，总增量上限为 +10 生命与 +2.5 幸运。

### 自我玩偶、音乐与白饭

自我玩偶显示当前玩家名字、皮肤与立体人物预览，支持托举、佩戴和摆放，摆放后保存皮肤归属。

成然系列摆放后右键循环播放《朋友的酒》，附近十六格生物定身、抖动与旋转，停止音乐或破坏来源后解除。余乐系列拥有抱鱼、眨眼、摇头和跳跃举臂动作，摆放后右键播放《Let Me Go》：摸鱼版十六格内每 1.6 秒提供白饭与瞬间治疗 XXIX；闲游版十二格内的玩家及驯服宠物获得八秒生命恢复 II，每目标间隔六十秒。歌曲范围内有音乐优先处理，保留普通战斗和脚步音效。

白饭可食用并给予瞬间治疗 XXIX；摸鱼神的鱼是可堆叠的蓝白像素普通物品，当前没有额外技能、食物属性或合成配方。

## 神格与饰品槽

每名玩家拥有 **一格神格、两格如我所书**，由 Curios 管理。五种玩偶可装入神格槽，普通头盔可同时保留；神格与头盔不能重复装备玩偶。神格槽使用坐姿玩偶线稿，书槽使用书本线稿。

“如我所书”目前仅有槽位，**尚无书籍饰品本体**。未来物品可加入 `starcrowndoll:as_written_accessories` 标签，也兼容旧 `curios:starcrowndoll_as_written`。永劫回归使用另一个 Curios「头部」槽，不占上述三格。历史独立槽数据有迁移机制；当前安装仍要求 Curios。[槽位文档](docs/divinity-slots-1.20.36.md)

## 永劫回归·三千万转

佩戴后显示高清立体内外神环、金色左翼与深紫金色右翼。神环悬浮在脑后、随身体朝向而非独立转头，具有金色泛光；致命回归沿用原版图腾展示时序，中央只显示立体内环。

| 系统 | 玩法 |
|---|---|
| 柴薪 | 用背包光标拿起物品组，在神环上右键焚烧，或反向操作；上限 33,550,336，随饰品保存。容器内容一起销毁，不另外计价；满额停止消耗 |
| 常驻 | 最大生命 +40%、最终伤害 +20%、普通最终伤害降低 20%；每百万柴薪与每层永久记忆各加 1% 最终伤害，相关加成合计上限 +250% |
| 火种 | 对有效敌人直接近战或本人投射物命中，每秒最多一枚，上限十二；脱战十秒清空 |
| 轮转 | 十二火种后按 G 开启，再按 G 提前终结；冷却九十秒。普通持续十六秒，有足够柴薪时消耗 10,000 强化为二十秒 |
| 轮转收益 | 最终伤害额外 +80%、移速 +25%、40% 最大生命护盾与击退免疫；积累直接伤害的 25%，强化为 35%，蓄伤最多为开启时攻击力四十倍 |
| 终结 | 800% 开启时攻击力 + 蓄伤，强化再 +50%；主目标获得 70%，十二格内其他敌人均分 30%，无其他目标则主目标全吃；没有有效敌人不自动攻击普通动物或友方 |
| 致命回归 | 普通致命伤时回到约六秒前同维度安全记录，生命至少为当前上限 50%，免伤两秒；冷却 180 秒，优先于普通图腾，但不挡 `/kill` |
| 记忆与觉醒 | 每次回归加一层永久记忆，最多三十；满层回归使下次命中终结额外 +50%。首次柴薪满额永久觉醒，觉醒后回归可免除下一次强化轮转柴薪消耗 |

柴薪不是纯收益：百万起分档减少最大生命，五百万起降低治疗，更高档增加承伤；满额时基础生命修饰净 +5%。轮转结束有二十秒疲惫，回归有记忆伤痕、八秒因果锁、清空吸收生命、正面剩余时长减半及十秒禁止自然回血。记忆与冷却不会因摘下、换饰品或重登重置。完整价格、档位、公式与保存规则见 [永劫回归玩法说明](docs/eternal-return-1.20.44/玩法说明.md)。

## 王律之键、Ea 与恩奇都

### 拔剑与收回

手持王律之键长按右键 **八秒**。钥匙展开三面解析塔，手伸入金球，随后出现短暂反相、黑场、指节白芒与破面碎裂；完成后当前手钥匙替换为 Ea，红纹从护手依次亮至剑尖，并召唤恩奇都。提前松手取消。

**1.20.72 修正**：入球时保留玩家手与袖子的原色；黑场白芒包含亮核、宽晕和四束白光。Ea 正反朝向、双手及拔剑交接保持一致，避免旧钥匙在结束后短暂重现。

手持 Ea **潜行并对空右键**，将其收回为王律之键，同时遣返自己的恩奇都。恩奇都是非战斗跟宠，无血条、不可选中、不受伤；自动待机、跑步、寻路跟随，掉队、换维度、重进或重生时尝试在主人附近重新出现，每位主人一只。[跟宠说明](docs/enkidu-1.20.54.md)

### 天地乖离开辟之星

手持 Ea 按 `[` 循环选择：天地乖离开辟之星 → 王之财宝普通二十门 → 全力一百门 → 天之锁，物品记住所选技能。

选中天地乖离开辟之星，按住右键起转 **两秒** 后开始日语《叙说原初》吟唱，默认吟唱 521 tick（26.05 秒），结束自动释放；提前松开可以取消。1.20.72 使用与 1.20.58 相同的日语吟唱音轨。旋转、吟唱及发射声音跟随施法者，吟唱期间暂停原版背景音乐，结束或取消后续播。

## 王之财宝与天之锁

### 王之财宝

Ea 对应技能，或独立王之财宝道具右键使用。独立道具潜行右键切换二十门/一百门。门阵在身后以有进深的横向矩形展开，金门保持正圆，门心光、同心波峰与薄金边逐步显现，武器从门中探出。

- **点按**：每门一把武器，分批齐射。
- **持续按住**：每射出一把武器，同一 tick 补开一扇门；松手只停止补门，已有门继续射完。
- **准心制导**：在飞武器持续跟随准心转弯，Ea 留在施法者手中。
- **命中**：直击及附近目标分别结算一次 20 点真实伤害，配金色冲击环和四尖碎星，方块保持完整。
- **轨迹**：起飞金屑、沿实际转弯轨迹收细的金丝；密集齐射只显示部分尾迹。

武器池支持当前游戏武器及单人创造栏变体。整合包可用 `starcrowndoll:treasury_weapons` 添加、`starcrowndoll:treasury_weapon_exclusions` 排除，并在 `data/<命名空间>/treasury_weapon_variants/*.json` 声明 NBT 变体，例如：

```json
{"weapons":[{"item":"minecraft:iron_sword","nbt":{"CustomModelData":3}}]}
```

### 天之锁

Ea 天之锁模式或独立道具，对准 **32 格内可见的敌对怪物**右键。五至六扇金门在目标周围开启，链条伸出、缠紧并持续固定目标，金色锁纹贴合模型；再次右键主动解除，目标死亡自动结束。

## 誓约胜利之剑与阿瓦隆

圣剑、空鞘和入鞘状态均使用有厚度、UV 与专用贴图的 OBJ Mesh。圣剑模型约 1.61 格长，保留银刃、蓝柄与金色护手；金面高光随视角和环境亮度变化。[Blender 工程](models/excalibur/Excalibur_and_Avalon.blend)

### 圣剑与风王结界

| 操作 | 效果 |
|---|---|
| 左键 | 基础总攻击伤害 12，攻击速度 1.6，不损耗耐久 |
| 潜行右键 | 隐匿/显现剑身，切换间隔 0.4 秒 |
| 隐剑按住右键 | 偏转正面箭与三叉戟；蓄力至少 0.6 秒松开发动风王铁槌，最远 24 格、基础伤害 12 并击退，随后显形，冷却三秒 |
| 明剑按住右键 | 举剑 0.5 秒后开始蓄光，可松键继续瞄准；从第一段声音开始计 11.60 秒自动发射，最远 64 格、基础伤害 40、可贯穿路径上多个目标，冷却十五秒 |

风王结界以流动白色风压覆盖隐形剑身；普通第一人称渲染可轻微扭曲背后纹理，第三人称及外部光影环境采用透明风纹。两种技能在有碰撞方块处停止，不破坏地形，跳过盟友和自己的驯服生物并遵守 PvP 设置；伤害受护甲等因素影响。

第一人称平时单手竖持；蓄力时宽剑面朝向玩家，两只原版皮肤手臂上下握住蓝柄，保留经典臂、细臂和袖层，另一只手的装备暂时隐藏，结束或中断后恢复。玩家周围 **七格半径**内升起最多 48 枚剑身同款金色光点。第一段声音末尾举剑过顶、喷出有厚度的金白能量柱，第一/第三人称均显示；停顿两秒后进入第二段声音，后蓄、下劈与自动出束对齐，落点呈现白金光柱、宽金环与贴地冲击。

蓄光前松手可取消，蓄光中切剑、换手或展开阿瓦隆可中断。风王铁槌与真名解放分别产生 1、4 点饥饿消耗值。

**仓库公开版圣剑使用 Kenney 无人声蓄力音效**，不等同于本机个人 Saber 日语原声版。已有两段个人 WAV 时可按 [资源包方法](docs/EXCALIBUR_ASSETS.md#个人日语资源包) 导入，动作与时序相同；Ea 日语吟唱是另一套独立音轨。

### 阿瓦隆·遥远的理想乡

| 操作 | 效果 |
|---|---|
| 随身携带 | 受伤时每四秒恢复一颗心，任一手持圣剑时每两秒；多份不叠加 |

## 永恒恶龙与荒芜之噬

永恒恶龙实体 ID 为 `starcrowndoll:minggulong`，拥有黑红生成蛋、原生 Cube/骨骼模型与动作、地面追击、飞行切换、四种爪击接触帧及完整死亡动画。生命上限 666，免疫火焰与岩浆，不显示着火效果。

## 配置、兼容与边界

客户端 `config/starcrowndoll-client.toml`：

| 配置 | 默认 | 说明 |
|---|---|---|
| `huangwuMode` | `LITE` | `LITE` 十二采样浓雾、`LEGACY` 历史体积、`BASIC` 原版几何、`OFF` 关闭荒芜视觉；改模式后 F3+T 重载 |
| `huangwuLiteMaxPixels` | `360000` | 轻量积分像素预算 |
| `huangwuVolumeResolution` | `0.5` | 宽高比例，可在 0.25～1.0 间调整，轻量模式另受像素预算限制 |

这些画质设置不改变服务端伤害、技能范围和时长。高级着色器失败时可降级基础几何。外部光影与第三方 HUD 的所有组合并未全部验证。

通用配置 `config/starcrowndoll-ea.toml` 的 `chantTicks` 默认 521，只控制吟唱段，不包含起转两秒；替换个人音轨时应保持时序对应。柴薪价格通过 `data/<命名空间>/kindling_values/*.json` 扩展，宝库武器通过前述标签与变体 JSON 扩展，玩偶分类通过 `starcrowndoll:dolls` 或继承 `WearableDoll` 扩展。

至高神性面向强能力玩法，但第三方 Boss 的私有血量、独立护盾、跨 UUID 复活和原生内存操作不保证通用拦截。“代价”只结算已加载、存活、非友方目标，取下、离线或离开同维度后取消，不补发离线伤害。Ea 会实际破坏允许破坏的地形，圣剑与宝库的保地形规则不适用于 Ea。
